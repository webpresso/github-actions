# Qualify caller setup resolution

## Product wedge anchor

- **Stage outcome:** The public reusable-workflow stage delivers deterministic, tokenless tool installation for Webpresso consumer CI.
- **Consuming surface:** .github/workflows/self-test.yml exercises .github/actions/setup-webpresso-toolchain/action.yml and .github/actions/setup-wp/action.yml on GitHub-hosted runners.
- **New user-visible capability:** Consumer workflows can rely on qualified Vite+ manifest/catalog resolution and a setup-wp cache miss that demonstrably becomes a cache hit without credentials.

## Summary

Add narrow GitHub-runner qualifications for setup-vp manifest-range/catalog resolution and setup-wp writable two-pass cache seed-to-hit behavior. Keep PR #54's staged rollout only as provenance; do not change public release routing or credentials.

**Wave:** 1
**Lane:** qa
**Depends:** None

Extend existing YAML-parsing contract tests rather than source-text-only assertions.

- [_] A colocated parsed-YAML contract test asserts fixture cases, immutable pin, expected version, and no duplicate install.
- [_] bun test and actionlint pass.

#### Task 99.2: Qualify setup-wp cache miss-to-hit behavior on a runner

**Status:** __wp-task-status__
**Wave:** 2
**Lane:** qa
**Depends:** Task 99.1
**Produces:** runner-setup-wp-cache-receipt
**Consumes:** runner-setup-vp-resolution-receipt, public-tokenless-setup-wp-contract

Add a separate runner qualification for setup-wp cache lifecycle. Override RUNNER_TOOL_CACHE to runner temp, run local setup-wp against the public release, assert its exact seeded cache path, then run it again with a nonexistent release-repo and prove wp works. A second download or unseeded cache must fail. Extend parsed contract tests.

**Acceptance:**
- [_] The cache qualification uses a writable runner-local RUNNER_TOOL_CACHE and invokes local setup-wp once at the existing exact public product version.
- [_] It asserts the first pass seeded the exact version-and-architecture path.
- [_] The second invocation uses the same version and a deliberately nonexistent release-repo yet succeeds and runs wp, proving a seeded cache hit rather than a network fallback.
- [_] A colocated parsed-YAML contract test asserts ordered passes, exact version, cache assertion, invalid-network control, and immutable references.
- [_] bun test and actionlint pass; sanctioned wp ci-act is attempted when local prerequisites are available.
